## Evidence and findings

HomeQ publishes API documentation aimed at integrations and third-party consumers. The documentation requires an API key obtained through landlord-portal integration settings and describes public API endpoints. The reviewed top-level documentation did not establish that FlyttSignal may read the required listing lifecycle data or define the allowed downstream use.

- API documentation: https://api.homeq.se/api-docs/
- Public API reference: https://api.homeq.se/api-docs/public
- Core API documentation: https://docs-core.homeq.se/

The existence of documentation is not permission. Do not create an account, request a key or integrate without an approved relationship and exact endpoint/use-case confirmation.
