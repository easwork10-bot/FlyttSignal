## Evidence and findings

SCB states that PxWebApi 2 launched in October 2025 and provides GET access to all tables in the Statistics Database. The published limits are 150,000 data cells per request and 30 calls per 10 seconds per IP. PxWebApi 1 remains available only until the turn of 2026/2027.

- API overview: https://www.scb.se/vara-tjanster/oppna-data/pxwebapi/
- Selected table metadata: https://api.scb.se/OV0104/v2beta/api/v2/tables/TAB6640?lang=sv
- Selected data query: https://api.scb.se/OV0104/v2beta/api/v2/tables/TAB6640/data?lang=sv&valueCodes%5BRegion%5D=0380&valueCodes%5BAlder%5D=TOT1&valueCodes%5BKon%5D=TotSa&valueCodes%5BContentsCode%5D=*&valueCodes%5BTid%5D=top(1)&outputFormat=json-stat2
- SCB usage terms: https://www.scb.se/om-scb/om-scb.se-och-anvandningsvillkor

This is aggregated statistics, not a property-level move signal. The adapter must never emit a property event or contribute directly to FlyttScore.

## Implementation gate

The selected table is `TAB6640`, with region `0380`, total age `TOT1`, total gender `TotSa`, all nine metric codes and the newest period. The captured response contains nine cells. SCB's v2 page states 150,000 cells per request while a general open-data page still mentions 100,000; this adapter remains safely below both and polls at most weekly. It includes timeouts, bounded retries, a response-size limit, strict schema-drift detection and a default-off kill switch.
