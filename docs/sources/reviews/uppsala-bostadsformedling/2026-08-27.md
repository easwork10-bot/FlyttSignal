## Evidence and findings

Public listing pages expose rental attributes and lifecycle-relevant dates. The organisation also describes a landlord portal/API, but that API is for landlords submitting housing into the mediation process. It does not establish a public read API or grant automated reuse.

- Public listings: https://bostad.uppsala.se/lediga-bostader/
- Landlord portal/API context: https://www.bostad.uppsala.se/hyresvardar/personlig-formedling
- Queue and mediation rules: https://www.bostad.uppsala.se/vagen-till-bostad/ko-och-formedlingsregler

`robots: index,follow` and HTTP 200 are not permission. The published queue rules govern service users; they are not a data-reuse licence.

## Required next action

Send the prepared `permission-request-draft.md` and ask for written permission or a documented public/partner read interface covering FlyttSignal's purpose, polling frequency, stored fields, retention and redistribution. Until then, do not implement polling.

If access becomes `GO`, removal detection still requires a complete run, volume sanity checks and at least two confirmed misses. A missing item must never be interpreted as “rented”.
